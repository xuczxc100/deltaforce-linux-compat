# Contributing

Useful next steps are independent Windows conformance tests for the registry-name edge cases, review of the Wine source diffs, and reproducible startup reports from other experimental prefixes.

Report the exact runner version, whether the stock package or a private copy was used, which changes were applied, and the last screen reached. Distinguish component-test success, startup, login, and a completed online session.

Do not attach game executables, proprietary drivers, account data, authentication arguments, full process dumps, or unreviewed raw logs. Include only the minimal redacted diagnostic output needed to explain the issue.

Please disclose substantial AI assistance in contributions and explain what was actually executed or independently checked. This repository currently contains experimental, AI-assisted work; an automated passing test is not a substitute for reviewing its expected behavior.
